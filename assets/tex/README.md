# Textures

All files in this folder are generated by `tools/gen_textures.py`: fully procedural,
deterministic (fixed seeds), no source images. Public domain / CC0.

Regenerate with `pip install --user pillow numpy scipy && python3 tools/gen_textures.py`
(about 1.5 minutes; pass names such as `grass_rough sand` to rebuild only some).

## Conventions

- Everything tiles in both axes (the clouds tile horizontally only).
- **Detail maps** (`grass_*`, `sand`, `soil`, `macro`) are near-neutral grey with a mean of
  0.5 (128) per channel. They modulate a base colour: `final = base * detail * 2`.
  Load them as linear data (`NoColorSpace`), not sRGB, so 128 means 0.5 in the shader.
- **Normal maps** (`*_n`) are tangent space, OpenGL convention: red = +X (right),
  green = +Y (up the image), flat = (128, 128, 255). Load as linear data.
- `bark`, `foliage` and `clouds` are colour textures (sRGB).

## Files

| File | Size (px) | World size / use |
|------|-----------|------------------|
| `grass_fairway.webp` + `_n` | 1024² | ~1 yard square. Short mown grass; blades lean slightly toward the top of the image (−V). Fairway and tee. |
| `grass_green.webp` + `_n` | 1024² | ~1 yard square. Putting surface: finer, denser, low contrast. |
| `grass_rough.webp` + `_n` | 1024² | ~2 yards square. Long, clumpy grass with deep normals. |
| `sand.webp` + `_n` | 1024² | ~2 yards square. Fine grains and gentle wind ripples (mostly in the normal map). |
| `soil.webp` + `_n` | 512² | ~3 yards square. Lake-bed mud and pebbles, for under shallow water. |
| `macro.webp` | 512² | ~60 yards square. Grey, mean 0.5, very soft blotches to break up tiling (use one channel). |
| `bark.webp` + `_n` | 512×1024 | Colour bark, vertical ridges (V runs up the trunk). Wrap U once or twice around a trunk. |
| `foliage.png` | 2048×512 RGBA | Atlas of four 512² slots, light grey-green, to be tinted per tree. 0: broad-leaf twig spray (face on, stem at bottom). 1: pine needle tuft hanging from the top edge. 2: palm frond, base at bottom, tip at top. 3: opaque tileable dense leaves for canopy bodies. Transparent pixels carry bled leaf colour (no dark mip fringes). |
| `foliage_n.png` | 2048×512 | Normal atlas matching `foliage.png` (flat where transparent). |
| `clouds.png` | 2048×512 RGBA | Equirectangular sky band: x = azimuth 0–360° (wraps), top row ≈ 40° elevation, bottom row = horizon. Stylised cumulus, white tops and blue-grey undersides, alpha = coverage. |
| `water_n.webp` | 1024² | Soft rounded ripple normals; scroll two copies at different scales and directions. |
